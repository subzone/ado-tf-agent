What you get

Everything Terraform needs
in Azure DevOps

A complete solution from provisioning Terraform on the agent to rendering rich plan output — without leaving your pipeline.

🚀

Full Lifecycle Pipeline Task

One task, six commands. Install a specific Terraform version, configure remote state, validate configurations, plan and apply — all in a consistent, reusable step.

install init validate plan apply show
☁️

Multi-Cloud State Backends

Native support for Azure Blob Storage, AWS S3 (with DynamoDB locking), and Google Cloud Storage. Or bring your own backend config file for any other provider.

azurerm s3 gcs custom
📊

Interactive Plan Visualization

A dedicated build results tab renders your plan.json as a filterable table with color-coded actions, expandable before/after attribute diffs, and resource counts.

🔗

Real Dependency Graph

Automatically derives the actual resource dependency graph from configuration.references in your plan and renders it as a Mermaid flowchart.

🛡️

Built-in Policy Checks

Scans planned resources for 10+ security misconfigurations: public S3 buckets, open security groups, unencrypted RDS/EBS, IAM wildcards, Azure public access, and more.

💬

PR Comment Integration

Automatically post a Markdown plan summary as a pull request thread comment so reviewers see add/change/destroy counts and resource details before approving.

      Get started
      
Up and running in minutes

    


    

      

        
1

        

          
Install the extension

          
Search for ADO Terraform Agent in the Visual Studio Marketplace and install it to your Azure DevOps organization. No tokens or credentials required.

        

      

      

        
2

        

          
Add pipeline steps

          
Drop the task into your azure-pipelines.yml. Use the configurator above to generate the exact YAML for your setup.

        

      

      

        
3

        

          
Run — and click the Terraform tab

          
After the pipeline runs, open the build summary. A Terraform tab appears automatically with the full plan visualization.

        

      

    


    

      

        azure-pipelines.yml — complete example
        
      

      
# azure-pipelines.yml
trigger:
  branches:
    include: [main]

pool:
  vmImage: ubuntu-latest

steps:
  - task: subzone.ado-tf-agent.terraform-task.Terraform@0
    displayName: Terraform install
    inputs:
      command: install
      terraformVersion: '1.7.5'

  - task: subzone.ado-tf-agent.terraform-task.Terraform@0
    displayName: Terraform init
    inputs:
      command: init
      workingDirectory: '$(System.DefaultWorkingDirectory)/infra'
      backendType: azurerm
      azureResourceGroup: my-tfstate-rg
      azureStorageAccount: mytfstateaccount
      azureContainer: tfstate
      azureStateKey: prod/terraform.tfstate

  - task: subzone.ado-tf-agent.terraform-task.Terraform@0
    displayName: Terraform validate
    inputs:
      command: validate

  - task: subzone.ado-tf-agent.terraform-task.Terraform@0
    displayName: Terraform plan
    inputs:
      command: plan
      workingDirectory: '$(System.DefaultWorkingDirectory)/infra'
      publishPlanArtifact: true
      postPrComment: true
